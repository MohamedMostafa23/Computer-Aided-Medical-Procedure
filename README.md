# Medical Image Computing and Computer-Assisted Procedures

A collection of Technical University of Munich (TUM) course projects on medical-image analysis. The notebooks show how classical image processing and machine learning can be used for registration, segmentation, classification, and 3D visualization.

![OCT exercise volume rendering showing a surgical instrument approaching a tissue surface](CAMP%20Classical/OCT/images/OCT_Volume_Rendering.png)

*Volume rendering from the optical coherence tomography (OCT) exercise.*

## Start here

| Project | What to look for |
| --- | --- |
| [OCT and instrument visualization](CAMP%20Classical/OCT/solution.ipynb) | Explore OCT slices, segment an instrument, and visualize the volume. [Figures and exercise overview](CAMP%20Classical/OCT/README.md). |
| [Liver endoscopy segmentation](CAMP%20AI-Based/Segmentation_Exercise.ipynb) | See how the image/mask pairs are prepared and how the notebook visualizes predictions from the segmentation pipeline. |
| [Ultrasound-to-CT registration](CAMP%20Classical/Registration/E04_registration_solution/US-CT-registration-solution.ipynb) | Follow an example of aligning images acquired with different modalities. |
| [Liver endoscopy classification](CAMP%20AI-Based/Classification_Exercise.ipynb) | Review dataset preparation and model training for a classification task on endoscopy images. |

## Browse by method

- [Classical methods](CAMP%20Classical/): image enhancement, intensity-based registration, ultrasound processing, and OCT.
- [AI-based methods and visualization](CAMP%20AI-Based/): classification, segmentation, registration, meshes, and volume rendering.
- [Chest X-ray processing](CAMP%20Classical/Image%20Processing/Ex01_Image_Processing_Solution.ipynb): a compact example of classical image enhancement.

These are course exercises and demonstrations. Some notebooks refer to data distributed separately during the course.
